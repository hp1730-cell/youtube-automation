YouTube自動化

プライバシーポリシー

制定日：2026年10月21日

「YouTube自動化」（以下「本アプリ」）は、運営者個人が自分の YouTube チャンネルに動画を投稿するために作成した、個人用のツールです。本アプリが扱う情報とその取り扱いについて、次のとおり定めます。

1. 本アプリの目的

本アプリは、運営者が制作した動画を、運営者本人の YouTube チャンネルに「非公開」の状態でアップロードするためだけに使用します。一般の利用者に向けたサービスではなく、運営者以外のアカウントで利用することはありません。

2. 取得する情報と権限

本アプリは、Google の OAuth 認証を通じて、次の権限のみを利用します。

  • YouTube Data API の動画アップロード権限（https://www.googleapis.com/auth/youtube.upload）

動画のアップロードと、アップロードした動画のタイトル・説明文・サムネイルの設定以外の操作は行いません。視聴履歴、登録チャンネル、コメント、連絡先など、その他の個人情報は取得しません。

3. 情報の保管

認証に必要なトークンは、運営者が管理する環境（暗号化されたシークレット保管領域）にのみ保管し、動画のアップロード処理のときだけ使用します。

4. 第三者への提供

取得した情報を第三者に販売・提供・共有することはありません。また、広告やその他の目的に利用することもありません。

5. Google API の利用について

本アプリによる Google API から受け取った情報の利用と移転は、Google API Services User Data Policy（限定的使用の要件を含む）に従います。

6. アクセス権の取り消し

本アプリへのアクセス許可は、Google アカウントのサードパーティ製のアプリとサービスの画面から、いつでも取り消すことができます。取り消した場合、本アプリはそれ以降 YouTube にアクセスできなくなります。

7. お問い合わせ

本ポリシーに関するお問い合わせは、Google の認証画面（OAuth 同意画面）に表示されている連絡先メールアドレスまでご連絡ください。

8. 改定

本ポリシーの内容は、必要に応じて改定することがあります。改定した場合は、このページの制定日の下に改定日を記載します。
